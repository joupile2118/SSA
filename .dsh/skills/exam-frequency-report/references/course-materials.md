## 4. 分级口径（全课程统一，勿改）

与 `SKILL.md` §3 一致。跨章报告必须沿用同一口径，否则各章之间无法比较。

- **核心考点（primary）**：该小问主要考的**就是本章内容**，不掌握则无法动笔 → **分值全额计入**，
  且**每个小问只归一个主考点**。
- **间接涉及（support）**：题目主体属别的章，但解题必须用到本章某个结论 → **不计分**，
  只记"涉及"。
- **八套版统一分级**：S为核心总分≥30且主归属命中≥3套；A为正核心分且（总分≥15或命中≥2套）；B为其他正核心分；C为0核心分。0核心分且支持涉及≥4套的考点另列为前提型。分级只用于当前八套描述，不作未来考试概率预测。

## 6. 工作区约定（来自 `README.md`，出交付物时必须遵守）

- **`output/` 只放交付物**：`.tex` 与 `.pdf` 成对放在一起，不混入 `.aux/.log/.toc`。
- **编译到 `tmp/`，再把 PDF 拷回 `output/`**：
  ```sh
  cd "<workspace>"
  xelatex -interaction=nonstopmode -output-directory=tmp/report "output/试卷/SSA_CH1_Exam_Frequency_Report.tex"
  cp tmp/report/SSA_CH1_Exam_Frequency_Report.pdf "output/试卷/"
  ```
- **`.tex` 必须自包含**（无 `\input`、无外部图片依赖），单个文件即可重编译。
- **中文必须 XeLaTeX**；纯英文文档才可用 pdflatex。
- 工具链：**TeX Live 2025**（`/Library/TeX/texbin`）。
- 教材转录与插图**保真优先 / 矢量优先**（原书笔误原样保留并加注释，插图用 TikZ 重画）。

## 7. 第 1 章报告中已经踩过的坑（其他章大概率复现）

| 现象 | 原因 | 处理 |
|---|---|---|
| 真题公式/分值抽错 | `pdftotext` 丢上下标与空公式 | 必渲染页面图像人工核对（SKILL §2） |
| `Overfull \hbox (17.0pt)` | `\rule{\textwidth}` 或 `tabularx` 处于段落开头，吃进 `\parindent` | 前面加 `\noindent` |
| 页宽与 iPad 不吻合 | 用了机身比例而非**屏幕**比例 | 见 SKILL §9 |
| 中文不显示 | 用了 pdflatex / 非 ctex 文档类 | `ctexart` + xelatex |
| `! Font TU/STFangsong ... not loadable`，且 `\texttt` 里的中文变乱码 | **CJK 文档里加载了 `newtxtext`**：它会破坏 ctex 的"CJK 等宽槽"映射，ctex 退到 `macold` 字体集，而其中文字体（STSong/STFangsong）在当前 macOS 上已不存在 | CJK 文档**删掉 `newtxtext`**，保留 `newtxmath`（实测无害）；`\setCJKmonofont` **修不好**。纯英文文档可照常使用 `newtxtext`（如 `SSA_CH1_Review_Problem_Set.tex`） |

> 已实测的触发条件：`ctexart + \texttt{中文}` → 正常；`ctexart + newtxtext + \texttt{中文}` → 报错并乱码。
> 第 1 章报告（`SSA_CH1_Exam_Frequency_Report.tex`）没有加载 newtx，所以侥幸正常——
> 但它引用了本技能早期的 `report-preamble.tex`，该文件曾含此 bug，现已修正。
