# SSA 作业与答案

先读工作区 `README.md`、`AGENTS.md`。本 skill 是该课程的本地工作流；路径均相对工作区根目录。用户的语言、题单、截止日期及格式要求优先于以下默认值。

双 Agent 分工见根目录 [WORKFLOW.md](../../../WORKFLOW.md)：DSH 构建并交接教材；作业发布后 Codex 按“题册 → 作业答案 → 考频分析 → 复习习题集 → 习题集答案”逐份验收交付，无需逐份再次确认。章号与作业批次号分别登记，已有成品先核对复用；用户此次明确只要部分文档时以此次范围为准。

## 确定交付范围

- 区分“题册”“答案”“两者”；只生成用户要求的部分。沿用已经确认的题号、顺序与语言，不因新一轮请求丢失用户更正。
- 默认英文，与第一次作业一致；题册明确是中文教材的忠实英译，不称官方英文原文。答案也用英文，按小问分步推导。
- 必做在前、选做在后，各组保持用户顺序。重复题号先指出；无进一步更正时只收录一次并按必做处理，不能猜测缺失题号。
- 将“今天起两周”按用户当地日期加 14 天；只用于这次作业，不改旧作业日期。没有日期就不编造。答案无需学生填写栏或截止日期。
- 查已有作业题册的 `\problem{题号}{分类}{书页}`，确保答案一一对应。当前已确认清单见 [references/course-notes.md](references/course-notes.md)。

## 提取与保真

优先使用 `output/教材/SSA_Textbook_CH<n>_zh.tex`，用 `\exer{n.k}` 定位，读到下一题开始；跨原书页的题目必须读全。LaTeX 不存在时再查看原教材扫描页。不要重复 OCR 已转录章节。

保留全部小问、参数、随机变量假设、图表及原书页码；英文术语沿用 `output/作业/SSA_Homework_1_English.tex`。两两独立不能翻译成相互独立，均方值不能译成方差，正态第二参数是方差。教材疑似错误不直接改题面：源码注明，在答案中解释后给出严格结论和必要时明确标注的“附加假设下的常见解法”。

## 排版

- 题册参考 `output/作业/SSA_Homework_1_English.tex`；答案参考修订后的 `output/作业/SSA_Homework_1_Solutions_English.tex`。可复用 [assets/homework-preamble.tex](assets/homework-preamble.tex) 和 [assets/solutions-preamble.tex](assets/solutions-preamble.tex)，复制进最终文件并修改章号、标题、日期、PDF 元数据；不要 `\input` 这些资源。
- 五份下游文档统一 iPad 竖屏比例2048:2732（纸高297mm、纸宽222.6413mm）。题册12pt，用于Notability手写，统一页眉、姓名学号、Required/Optional、原书页码、Answer / Working 留白，**每题一页**。答案11pt，用于电脑阅读，逐题对应、分步推导、关键结果用 `\boxed`，**连续自然分页**，不强制每题一页，不添加手写留白；不单独添加封面。
- 必须画出的图形用 TikZ 内嵌，不依赖外部图片。CDF 标注端点、跳跃及定义域；联合 CDF 可以用明确标注高度的分区图表示。
- 答案标题前用 `\Needspace{8\baselineskip}` 防止标题孤立页底；长解答可以跨页，不为凑一页缩字或删关键论证。题册题面确实放不下一页时再说明必要分页。索引/长表用longtable或xltabular按空间自动分页，禁按固定行数手动分块。详见考频技能的“SSA pagination”规则。
- 最终文件成对放在 `output/作业/SSA_Homework_<n>_English.tex/.pdf` 与 `SSA_Homework_<n>_Solutions_English.tex/.pdf`。源码自包含。中间产物仅放 `tmp/`；不改顶层输入或历史提交稿。

## 解题与核验

先独立求解再写最终答案。每个小问都要有结果与足够依据，不能用“显然”“认出”跳过正在学习的关键步骤。尤其注意：

- PDF 独立性判据：先计算边缘密度，或解释因子为何各自归一化，并检查支持域；零协方差只有在**联合正态**等适用条件下才能推出独立。
- 区分 PDF 归一化、均值与二阶矩；特征函数求矩说明采用正指数约定和导数关系。
- 先检查协方差矩阵的行列式/秩，再用高斯 PDF；奇异时给出支撑约束及有效的特征函数或广义密度，不能强行求逆。
- 三个变量的两两独立不保证乘积与第三个独立；需要因子分解的步骤必须核验假设。
- 退化时刻、零方差、负缩放、CDF 边界、Dirac/Kronecker delta 都要正确处理；题目若不适定，解释原因而不是编造唯一答案。

具体已知题目陷阱只在 [references/course-notes.md](references/course-notes.md) 中维护。数值答案用另一种推导或独立脚本验证；有限分布用精确枚举，矩阵用乘法/秩检查，积分可用数值求积。数值近似只能交叉验证，不能代替奇异性等精确证明。

## 编译、验收、交付

若当前环境提供 PDF 技能，遵守其创建/编辑标记与最终文件引用要求。使用本 skill 的自动检查脚本：

```bash
python3 .dsh/skills/ssa-homework/scripts/build_check.py \
  --tex output/作业/SSA_Homework_2_Solutions_English.tex \
  --required 2.3,2.13,2.16,2.19 --optional 2.1,2.4,2.7,2.8,2.11,2.18 \
  --build-dir tmp/homework2_solutions --render
```

脚本用 XeLaTeX 编译两遍，检查 0 overfull、无缺字、无未解析引用，核对源码与 PDF 的题号顺序、分类、自包含及2048:2732比例；题册检查每题一页，答案检查跨页连续题号与分类（自动从Solutions文件名识别，也可用`--layout reading`），然后拷回 PDF。题册有日期时可增加 `--issued '13 October 2026' --due '27 October 2026'` 检查每页日期。英文标识是此脚本的接口；若生成中文文档，需要相应调整解析逻辑，而非跳过验收。

**自动验收不验证数学正确性，也不代替目视检查。** 渲染每页，查看全页缩略图和相邻页衔接，排除因强制换页、不可拆表格造成的大块无意义空白；对新图、密集公式和易溢出页查看大图，修改后重编译重看。禁止只凭编译成功交付。

完成后更新工作区 README 的交付物索引；新题目清单、日期、重要数学例外登记到 course-notes。最终提供 PDF 与可编辑源码位置，说明页数及关键假设问题。不要把暂存脚本、日志、拼图作为交付物。
