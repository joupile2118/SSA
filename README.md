## 文件与使用方式

- `output/教材/`：中文教材重排版。
- `output/作业/`：英文作业题册与答案。
- `output/试卷/`：考频分析、复习习题集与中文详解。
- PDF 可直接阅读；同名 `.tex` 是对应的可编辑源码。中文文档请使用 XeLaTeX 编译。为避免中间文件混入交付目录，建议把编译输出指定到单独的临时目录。

本仓库收录的是前两章的上述成品，不包含原始教材扫描件、历年试卷或构建过程中的临时文件。教材原文及相关课程材料的权利归各自权利人所有；这些文档用于课程学习与复习。
